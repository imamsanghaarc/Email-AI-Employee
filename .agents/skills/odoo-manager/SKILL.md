# Odoo Manager Skill

## Overview
Manages business accounting, CRM, and ERP operations within Odoo Community.

## Usage
- Integration via MCP server: `mcp/odoo-mcp/server.py`
- Commands: Use natural language via Claude (e.g., "Show me unpaid invoices").

## Configuration
Requires Odoo URL, DB, Username, and API Key in `.env`.

## Dependencies
- Odoo MCP Server
- JSON-RPC access
