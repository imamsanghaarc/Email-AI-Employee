# LinkedIn Watcher

Monitors LinkedIn activity via Playwright browser automation and creates tasks for new opportunities.

## Overview

Watches LinkedIn for new connections, messages, and profile views. Creates structured task files in `AI_Employee_Vault/Inbox/` for AI processing and follow-up.

## Components

- **Script**: `scripts/watch_linkedin.py`
- **Output**: Creates `.md` files in `AI_Employee_Vault/Inbox/`
- **Log**: `logs/linkedin_watcher.log`
- **State File**: `logs/linkedin_watcher_state.json` (tracks processed activities)

## Usage

### Start LinkedIn Watcher
```bash
python .agents/skills/linkedin-watcher/scripts/watch_linkedin.py
```

### Configuration
Requires `.env` file with:
```env
LINKEDIN_EMAIL=your-email@example.com
LINKEDIN_PASSWORD=your-password
```

### How It Works

1. Opens LinkedIn via Playwright browser every 300 seconds
2. Checks for new activity:
   - New connections
   - New messages
   - Profile views
   - Job recommendations
3. For each new activity:
   - Extracts: name, type, details
   - Creates task file: `AI_Employee_Vault/Inbox/linkedin_{type}_{timestamp}_{name}.md`
   - Logs action to `logs/linkedin_watcher.log`
4. AI Employee processes task files via normal workflow

### Task File Format

```markdown
---
type: linkedin_connection
status: pending
priority: high
created_at: 2024-01-15 10:30:00
contact_name: John Doe
contact_title: CEO at Example Corp
activity_type: new_connection
---

# LinkedIn Task: New Connection - John Doe

## Details
- **Contact**: John Doe
- **Title**: CEO at Example Corp
- **Activity Type**: New Connection
- **Date**: 2024-01-15 10:30:00

## Suggested Actions
- [ ] Review contact profile
- [ ] Send personalized connection message
- [ ] Add to CRM or contact database
- [ ] Move to Done when complete

---
*Automatically generated by LinkedIn Watcher*
```

## Rules

- **Browser Automation**: Uses Playwright (no LinkedIn API needed)
- **Stateful**: Tracks processed activities to prevent duplicates
- **Non-Intrusive**: Read-only monitoring, no automated posting
- **Error Handling**: Gracefully handles browser failures
- **Resource Efficient**: 300-second polling interval
- **Security**: Credentials stored in `.env`, never logged
- **Session Management**: Maintains browser session to avoid repeated logins

## Activity Types Monitored

1. **New Connections**: Potential business leads
2. **Messages**: Direct messages requiring response
3. **Profile Views**: People viewing your profile (potential leads)
4. **Job Posts**: Relevant job opportunities

## Troubleshooting

**Login Failed**: Verify LinkedIn credentials
**Browser Error**: Ensure Playwright is installed (`playwright install`)
**Session Expired**: Script will re-login automatically
**Rate Limited**: Increase CHECK_INTERVAL if detected
