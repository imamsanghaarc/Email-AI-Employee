# 🥉 Bronze Tier - Basic Autonomous Monitoring

## Overview

The Bronze Tier provides foundational monitoring and task generation capabilities. It's the entry point for understanding the AI Employee framework and requires minimal configuration.

**Purpose:** File monitoring, task tracking, and log management

**Complexity:** Low | **Autonomy Level:** Basic

---

## Components

### 1. The Watcher (`watcher.py`)

A lightweight monitoring script that watches the Inbox for new files.

#### Features
- Monitors `AI_Employee_Vault/Inbox` every **5 seconds**
- Automatically generates structured task files in `AI_Employee_Vault/Needs_Action`
- Self-heals missing directory structures
- Simple, reliable, and resource-efficient

#### How It Works
```python
# Pseudocode
while True:
    files = scan(Inbox/)
    for file in files:
        if file not in processed:
            create_task_file(file)
            move_to_Needs_Action(file)
    sleep(5)
```

#### Running the Watcher
```bash
python watcher.py
```

**Output:**
- Creates task files in `Needs_Action/` with YAML frontmatter
- Logs activities to `System_Log.md`
- Updates `Dashboard.md` with file counts

---

### 2. Task Processor (`run_ai_employee.py`)

Processes pending tasks from Needs_Action and moves them to Done.

#### Features
- Scans `Needs_Action/` for pending tasks
- Updates task status to completed
- Updates Dashboard with progress
- Logs all activities to `System_Log.md`

#### Running the Task Processor
```bash
# Single execution pass
python run_ai_employee.py --once
```

**Note:** The root-level `run_ai_employee.py` is the Bronze Tier version. The Silver Tier version is at `scripts/run_ai_employee.py`.

---

### 3. Log Manager (`log_manager.py`)

Ensures system sustainability by preventing log overflow.

#### Features
- Monitors log file sizes
- Automatically rotates logs exceeding **1.5MB**
- Creates timestamped archives
- Prevents disk space exhaustion

#### Running the Log Manager
```bash
python log_manager.py
```

## Task File Format

Tasks generated by the Bronze Tier use this structure:

```markdown
---
type: file_review
status: pending
priority: medium
created_at: 2026-04-13 10:30:00
related_file: ["filename.md"]
---

# Task File: Review filename.md

## Description
Brief description of the task

## Checklist
- [ ] Action item 1
- [ ] Action item 2
- [ ] Action item 3
```

---

## File Lifecycle (Bronze Tier)

```
File added to Inbox/
  → Watcher detects (5s interval)
  → Task file created in Needs_Action/
  → Task Processor updates status
  → File moved to Done/
```

## Limitations

Bronze Tier does **not** include:
- ❌ LLM integration
- ❌ Daemon/scheduler mode
- ❌ Human approval workflow
- ❌ Error recovery/retry
- ❌ External integrations (email, social media, ERP)

**Need more autonomy?** Upgrade to [Silver Tier](SILVER_TIER.md) for:
- Daemon mode with configurable intervals
- LLM-driven task planning (5 API backends)
- Human-in-the-loop approvals
- Automated error recovery and retry

## Troubleshooting

### Watcher not detecting files
1. Verify `Inbox/` directory exists
2. Check file permissions
3. Ensure no other process is locking files

### Task Processor not moving files
1. Check `Needs_Action/` directory
2. Verify task file format (YAML frontmatter required)
3. Check `Dashboard.md` is writable

### Logs growing too large
- Log Manager should auto-rotate at 1.5MB
- Run manually: `python log_manager.py`
- Check `logs/` directory for archived logs
